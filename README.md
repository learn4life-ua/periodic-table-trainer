# Periodic Table Trainer

Інтерактивна періодична система хімічних елементів і тренажер для навчання та самоперевірки.

## Мета

Проєкт створюється як безкоштовний навчальний вебзастосунок, що поєднує:

- інтерактивну Періодичну систему;
- картки хімічних елементів;
- режими дослідження груп, періодів і блоків;
- тренувальні завдання з миттєвою перевіркою;
- роботу без реєстрації та збереження персональних результатів.

## Технології

HTML, CSS, JavaScript, JSON, GitHub Pages.

## Статус

Початкова версія в розробці.
